# 카페24 전체 상품 매핑 분리 전환 결과

2026-10-28 운영 DB(`meta_ads`)에 적용 완료. 이번 작업은 기존에 배포된 분리 매칭 기능의 **규칙 데이터와 기존 주문 연결**을 수정한 것으로, 앱 재배포는 하지 않았다.

주문번호나 고객 정보를 내보내지 않고 DB에서 직접 검사했다. 원본 주문 금액·수량·상품명·옵션값·원천 정보 등 조회한 매핑 외 필드의 해시가 적용 전후 동일하다. 규칙의 가격·원가·배송비·추가비용, 광고비 연결, ROAS 그룹, 우선순위, 유효기간, 활성 상태도 전후 동일하다. 규칙 수정과 주문 연결 변경은 한 트랜잭션으로 처리하고 보안 감사 이력을 저장했다.

상품별 매핑이 바뀐 행에는 해당 규칙에 이미 설정되어 있던 가격·원가가 적용되므로 계산 결과는 바로잡힌 분류를 반영한다. 원본 주문 결제액을 수정한 작업은 아니다.

## 실제 주문에서 확인한 수정 사례

- **바라클라바**: 상품명에 `1+1` 할인 안내가 있어도 원본 옵션이 `바라클라바 프로`이면 프로 단품으로 연결. 해당 주문 1행의 미매칭을 해결했다. 나머지 기본형/프로형 및 1+1 조합은 회귀 테스트로 검증했다.
- **풀업밴드**: 상품 식별 및 기존 캠페인 구분인 `🚀` 조건은 상품명에서 검사하고, 그린/퍼플/블랙/레드/SET는 옵션값에서 검사한다. 상품명의 `그린`, `SET`가 선택 옵션을 덮어쓰지 않는다. 세트로 잘못 연결되어 있던 그린 100행을 그린 규칙으로 수정했다. 크로스셀링/캠페인 규칙 간 이동도 기존 구분 조건을 각 필드에 맞춰 적용했다.
- **퍼펙트슬라이드**: 옵션의 `슬라이드`와 `프로`/`일반형`/`1+1` 조합을 검사한다. 상품명의 `고급 무릎패드`에 의존하지 않는다. 프로 단품에 연결된 1+1 주문 2행을 1+1로 수정했고, 케겔 일반형 추가상품 3행은 슬라이드 연결을 해제했다.
- **버닝 웨이브바·버닝 슬라이드·플로우라이트·유쉴드마스크·한줄보호대**: 제품 식별 단어는 상품명, 묶음 선택 단어는 원본 옵션값에서 검사한다. 상품명의 무료 증정 `+`가 묶음으로 판정되지 않는다.
- **아이언볼·자이로볼**: 같은 카페24 상품번호 `14`를 사용하는 경우에도 상품명을 함께 확인한다. 아이언볼 주문 1행을 자이로볼 아이언에서 아이언볼로 수정했다.
- **나머지 상품**: 수면안대, 양말, 러닝조끼, 스카이스텝, 베놈무릎보호대, 뷰티레그보드, 풀업바, 에어스텝퍼, 퍼펙트스케이트, 두줄무릎보호대도 상품 식별 조건을 상품명으로 옮겼다. 공동구매/유튜브/비밀링크 등 기존 제외 목적은 상품명 조건으로 보존했다.
- **방한마스크**: 앞서 전환한 2개 규칙을 유지했고, 단품 3행 / 1+1 6행 구분도 그대로 확인했다.

원본 필드는 카페24의 `product_name`, `option_value`를 각각 사용한다. 결합 표시 문자열을 특수문자로 분해하지 않는다. `+`, `1+1`, `🚀`는 원래 규칙에 있던 상품 구성/캠페인 조건이며 필드 구분자가 아니다.

## 기존 운영 설정을 보존한 범위

적용일이 나중에 조정됐거나 현재 비활성인 규칙으로 이미 올바르게 연결된 과거 주문 1,225행은, 새 필드 조건에 맞는지 확인한 뒤 기존 연결을 유지했다. 규칙의 활성 상태나 적용일을 임의로 바꿔 과거 가격 정책을 확장하지 않았다. 이 중 비활성인 두줄 단품 규칙에 연결된 과거 주문은 156행이다.

이번 스크립트는 이 과거 연결 보존 정책을 명시적으로 적용한다. 앱의 일반 전체 재매칭은 현재 활성 규칙과 유효기간으로 다시 판정하므로, 나중에 전체 기간 재매칭을 실행할 때 이 과거 연결을 별도로 검토해야 한다.

남은 미매칭 **826행**은 아래와 같이 확인했다.

| 이유 | 행 수 | 처리 |
| --- | ---: | --- |
| 등록된 상품번호 규칙 없음 | 632 | 새 상품/추가상품 규칙 등록 범위 |
| 규칙 또는 제품이 비활성 | 153 | 비활성 공동구매 에어스텝퍼 설정 보존 |
| 현재 규칙의 적용기간 밖 | 29 | 기존 유효기간 보존 |
| 추가상품 또는 미설정 옵션 | 12 | 슬라이드/자이로볼에 붙은 타 상품 11행, 구성 표시 없는 두줄 코랄핑크 1행 |

이 12행은 다른 제품으로 억지 연결하지 않았다. 정확한 추가상품 규칙이나 과거 단품/묶음 구성 확인이 있어야 연결할 수 있다.
