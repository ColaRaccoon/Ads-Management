## 구현
- [x] 구현일의 API 버전·접근등급·인증 문서를 재확인한다. 2026-09-21 확인 본문은 개발자 토큰 종료/Cloud 프로젝트 접근등급을 안내한다. 과거 tutorial의 token 필수 조건을 복사하지 않는다.
- [x] 서비스 계정 최소 계정권한 우선, 불가 시 사용자 OAuth offline 인증. Cloud project 실계정 접근등급·customer/MCC 경유·통화·시간대를 실제 요청으로 검증한다. 인증 수단은 구글 원본을 따라 보호 저장한다.
- [x] Google 공식 인증 라이브러리와 REST client를 사용한다. query는 서버에서 검증된 날짜로 만든다. 캠페인 날짜별 ID/name/channel/cost_micros/impressions/clicks, 계정 메타데이터를 수집한다.
- [x] Search pagination을 모두 처리하고 PMax·현재 중지된 캠페인의 과거 비용을 누락하지 않는다. 계정 일별 비용은 대조에만 쓰며 캠페인 합계에 더하지 않는다. 대상 계정에는 PMax가 없어 PMax는 합성 테스트로 검증했다.
- [x] 정수 micros·BigInt 저장과 JSON 문자열 직렬화, 표시 시 환산·반올림을 구현한다. 캠페인 행 공개 API는 아직 없으며 정밀도 경계 유틸과 테스트를 제공한다.
- [x] 계정×날짜의 완전한 스냅샷을 원자적으로 반영한다. 정상 0행이면 이전 비용 행을 정리하고 coverage를 남긴다. 403/중간 페이지 실패는 0원으로 덮어쓰지 않는다.
- [x] 계정×날짜의 완전한 스냅샷을 제한된 날짜 단위로 처리하는 공통 실행 계약을 사용한다. 2026-09-30의 최근 7일 격리 대조는 당시 실증 기록으로 유지한다. 2026-10-02 이후 운영 계획은 **7일마다 한 번, 계정 현지 기준 직전 완료 7일을 각 날짜 한 번씩** 읽는다. 지난 날짜의 반복 재조회·전월 보정·자동 과거 적재는 하지 않는다. 누락·늦은 수정은 coverage/마지막 수집 시각으로 표시하고, 관리자가 날짜 하나를 명시한 수동 복구만 허용한다.
- [x] 권한 실패·quota·잘못된 field/version·인증 갱신 실패를 구분하고 안전한 requestId를 남긴다.
