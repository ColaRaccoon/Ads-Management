# 01 — 운영 기준선과 외부 접근 조건
상태: **BLOCKED** — 운영 기준선과 격리 target, Google 전용 project/API·탐색자 접근·읽기 전용 서비스 계정, Cafe24 전용 주문 읽기 테스트 앱과 해당 용도의 API 무과금 공식 답변, Meta 전용 앱·광고계정 연결·`ads_read`의 계정/캠페인/광고세트/광고·전환/영상 필드 실조회 및 Meta API 별도 사용 비용이 없다는 지원 담당자 답변까지 확인했다. Google 실제 API 읽기, Cafe24 callback 이후 테스트 설치, Meta 지속 인증·Limited tier 일일 호출량·비즈니스 인증 처리, 명시되지 않은 계약 조건 확인이 남아 있다. 담당 세션은 이 단계만 수행한다.
필수 읽기: [공통 규칙](공통_작업규칙.md), [진행표](진행표.md), 구글 원본 1·3·6절, deploy/cloud/README.md 및 scripts/cloud/storage-renewal/README.md.
목표: 실제 운영을 건드리지 않고 세 원천을 검증할 환경·계정·비용 조건을 확정한다. 앱 기능 개발은 다음 단계다.

## 작업
- [x] 실제 운영 SHA/이미지, Railway 배포 브랜치·자동배포 trigger, replica·절전·health route·환경 참조, Supabase 프로젝트·schema·Auth·Storage·백업을 읽기 점검한다. 실제 비밀값은 출력하지 않는다.
- [x] 운영 일일 업무 목록과 대표 데이터·기존 로그인/업로드/조회/KPI의 기준선을 기록한다. 자동화 개발 중 사용자가 만드는 새 데이터도 보존해야 한다.
- [x] codex/ 격리 브랜치와 운영과 분리된 테스트 DB·Storage·Auth/컨테이너를 준비한다. 무과금 격리 환경을 우선한다. 운영과 다른 target fingerprint 및 테스트 실행의 prod 차단을 마련한다.
- [x] 기존 cron job 이름·시각·HTTP/Vault/권한만 조사한다. Storage 04:00/04:15/04:20 기록을 실제 값과 대조한다. 기존 cron.sql 재실행 금지.
- [x] 계정 목록을 확정한다: Google 고객·Cloud 프로젝트·관리자 경유 여부, Cafe24 mall/shop 번호·소유 관계, Meta business/ad account·앱 역할. 계정별 통화·시간대·기간·담당자를 기록한다.
- [ ] Cafe24 설치 경로·mall.read_order 가용성·개인정보 제한·특정 endpoint 승인, Meta ads_read/운영 티어·비즈니스 인증, Google 실계정 접근등급과 인증 방식을 확인한다. 필요한 외부 신청은 승인 범위 내 진행하며 대기 상태를 기록한다.
- [x] 기존 프로그램에서 필요한 데이터 항목에 대한 접근 가능 여부를 표로 만든다. 권한 부족/필드 누락을 자동화 가능으로 확정하지 않는다.
- [ ] Cafe24/Meta 요금·계약은 공식 명시 또는 계정 계약/공식 답변으로 확인한다. Cafe24 해당 범위 무과금과 Meta API 자체 별도 사용 비용·요금제 없음은 지원 답변으로 확인했으나 Meta의 별도 유료 계약·최소 결제 조건은 답변에 명시되지 않았다. 미확인 상태는 숨기지 않고 운영 활성화 전 해결 항목으로 남긴다. Google API 무료와 서버 비용을 분리한다.
- [x] Railway/Supabase 사용량·포함량·청구 기준선을 기록하고 추가 유료 서비스 없는 실행 경로를 정한다. 외부 고객 대상 SaaS는 범위에서 제외한다.
- [x] 세 원천의 credential 보관/최초 연결 방법과 계정 소유자의 해야 할 일을 구체화한다. 개인 비밀번호나 token을 대화로 요구하지 않는다.

## 산출물·완료 기준
records/01_환경과접근조건.md: 비밀값 없는 환경표, 계정별 READY/PENDING/BLOCKED, 계정 연결 절차, 요금 확인 증거, API 전환일 이전 CSV 보존 범위와 명시적 수동 하루 복구 절차, 운영 baseline과 격리 증거. 2026-10-02 비용 결정으로 자동 최근 30일 과거 적재 제안은 폐기했다.
records/01_결과.md: 완료/대기 분리. 운영 환경 미변경, 격리 환경 준비 및 권한 경로 확정이 필수다. 계정 승인 미완료라면 전체 DONE으로 처리하지 않고 02~04만 독립 진행 가능함을 적는다.
이번 요청에서는 다음 단계를 시작하지 않는다. 01 재개 시 Google 서비스 계정의 안전한 인증 경로와 실제 읽기, Cafe24 callback 이후 테스트 설치·주문 읽기 대조, Meta 지속 credential·Limited tier 일일 호출량·비즈니스 인증 처리와 명시되지 않은 계약 조건을 먼저 확정한다. Meta 상세 필드는 브라우저 임시 토큰으로 읽혔으나 지속 인증과 동일 기간 CSV 대조는 미완료다. Cafe24는 자사몰 1개에 `테스트 실행`으로만 설치하고 판매 등록·스토어 출시·`심사 요청`은 범위에서 제외한다. 해당 범위의 Cafe24 Admin API 이용료와 Meta Marketing API 자체의 별도 사용 비용 없음은 각각 공식 지원 답변으로 확인했다. Google 전용 manager는 생성됐으나 기존 광고계정 연결 요청이 실패했고, 현행 Ads API 접근의 필수 조건은 아니다.
