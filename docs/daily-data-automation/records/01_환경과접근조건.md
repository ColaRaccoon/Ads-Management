5. 최초 연결은 격리 앱 origin과 격리 DB/Auth/Storage에서만 수행한다. provider가 반환한 credential은 서버 전용 secret store에 저장하고, DB에는 암호화된 참조·만료·scope·account fingerprint만 둔다. `NEXT_PUBLIC`, 로그, fixture, 보고서에 원문을 넣지 않는다.

7. 2026-09-29 당시 기본 최초 과거 적재 범위는 **최근 30일**로 제안했다. **2026-10-02 사용자 비용 결정으로 자동 과거 적재 제안은 폐기했다.** API 전환일 이전 자료는 기존 CSV를 보존하고 필요한 이전 날짜는 관리자가 하나씩 명시해 수동 검토한다. 이 문단은 당시 제안과 이후 변경을 함께 보존한다.
