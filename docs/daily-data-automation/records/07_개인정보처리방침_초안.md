Meta 수집 경로는 광고를 본 개인의 명단·이름·연락처를 요청하지 않는다. 인증 확인 시 `/me`에서 ID만 요청하며, 자동 기본 `public_profile` 권한으로 추가 프로필 정보를 요청하지 않는다. 광고를 생성·수정하는 권한은 이 연동 범위에 포함하지 않는다. API가 제공하지 않거나 의미를 확정할 수 없는 지표는 사유와 함께 ‘확인 필요’로 표시한다.

Cafe24 API의 요청 필드는 구매자 이름·전화번호·이메일·배송지 주소를 포함하지 않는다. 주문번호는 다른 자료와 연결될 수 있는 정보로 취급한다. 기존 파일·다른 업로드 영역까지 개인정보가 없다고 단정하지 않는다. `[확정 필요: 실제 운영에서 활성화된 연동·기존 파일의 처리 항목 및 외부 서버 접속 로그 항목]`.

인증 쿠키를 사용하여 로그인 상태와 요청 위조 방지 정보를 관리한다. 브라우저 저장소에는 활동 시각, 탭 사이 인증 상태 조정 정보 및 화면 설정 등이 저장된다. 쿠키나 저장소를 차단·삭제하면 로그인 유지 및 일부 기능이 제한될 수 있다. `[확정 필요: 실제 게시 환경의 쿠키 수명·Secure 설정·외부 분석/추적 도구 사용 여부]`.
