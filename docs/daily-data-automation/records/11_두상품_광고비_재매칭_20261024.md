# 다이어트양말·러닝조끼 광고비 재매칭 — 2026-10-24

**요청 범위 완료.** 10/23 데이터의 두 상품 광고비를 기존 정상 관리자 화면에서 재매칭하고 DB·판매 화면에서 반영을 확인했다. 재매칭 코드 결함은 재현되지 않았고 제품 코드 수정·재배포는 없다.

## 원인

사용자가 두 상품과 Cafe24/Meta 규칙을 새로 만들고 Cafe24 판매 재매칭을 실행했다. 두 상품 규칙의 시작일은10/21, 상품과 규칙은 활성 상태로10/23에 적용 가능했다. 실제 Cafe24 판매 품목은 다이어트양말8행·러닝조끼3행 모두 제품 ID에 연결돼 있었다.

하지만 판매 화면의 `/sales/cafe24/rematch`는 Cafe24 주문 품목만 처리한다. Meta 광고비의 제품 연결은 별도 `/mappings/rematch`가 담당한다. 두 광고세트와 소속 광고4개의 productId는 아직 NULL/UNMATCHED였다. 최근 감사 이력의 Cafe24 재매칭은13:58~14:01KST에 존재했으나, Meta 재매칭은 이번 실행14:10KST에 처음 기록됐다. 규칙을 저장하는 것만으로 기존 광고 metric이 다시 계산되지는 않는다.

코드에서 날짜 유효성·선택된 CSV/API 원천·기존 수동 매핑 보존 경계를 확인했다. 운영 Meta Mappings의 **10/23 하루 → 자동매핑계산**을 한 번 실행해 정상 동작을 실증했다. Cafe24 재매칭의 범위를 광고까지 임의 확장하지 않았다.

다이어트양말은 제품/판매/광고 매핑은 완료됐지만 **ProductCostRule 자체가0개**이고 Cafe24 원가 override도NULL이다. 그래서 매출318,400원·쿠폰2,000원·광고비108,829원은 보이지만 총비용·마진은미계산이다. 이는 광고 매칭 실패가 아니며 0원 원가로 대체하지 않았다. 사용자가5켤레 구성의 원가·배송비·추가비용과 적용일을 입력해야 마진을 계산할 수 있다.
