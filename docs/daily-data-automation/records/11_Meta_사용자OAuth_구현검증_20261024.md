## 구현

- 자격 검증 두 모듈에 명시적 `DAILY_SYNC_META_AUTH_CLASS=USER` 모드를 추가했다. MCP 및 숫자로 된 앱 범위 사용자 ID `DAILY_SYNC_META_USER_ID`가 필요하다. 기본 SYSTEM_USER 경로와 기존 v1 암호문은 호환된다.
- USER 레코드는 v2 AES-GCM으로 앱·원천 연결·광고계정·MCP·인증 종류·사용자 ID에 결속된다. 실제 debug_token 및 /me 주체가 지정 사용자와 일치해야 하며 기존 앱, 최소 두 scope, USD/Asia/Seoul, 7일 초과 만료 여유 검사는 유지한다. 설정이 조회 도중 변경되어도 실패한다.
- 시작 스크립트는 USER 모드의 v2 암호문만 메모리 파일로 준비한다. 실제 복호화·주체 확인은 기존 보호 resolver가 수행한다. 원천 수집·예약 기능을 켜는 변경은 없다.
- C7 비교 허용 목록에 두 인증 모듈을 추가했다. 현재 성공 배포 대비 추가 API 변경은 두 모듈이며, C7 기준 총 11개 JS 차이만 허용한다. DB schema/migration과 프런트엔드는 변경하지 않는다.
