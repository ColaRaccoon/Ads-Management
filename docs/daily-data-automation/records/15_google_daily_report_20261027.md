# Google Daily Report

2026-10-27: 로컬 구현·검증 완료. 이 기능의 운영 배포는 별도 확인이 필요하다.

- `/google/daily-report` 및 왼쪽 Google 메뉴를 추가했다. 기존 공용 상단바 날짜 선택을 사용한다.
- Meta Daily Report와 동일한 카드·표·인쇄 스타일을 사용하며, 선택 기간의 종료일 하루와 직전 하루를 비교한다.
- 상품별 캠페인 지표, 카페24 `[유튜브]` 판매 기반 마진, 전체 요약, 제품/캠페인 검색, 광고비 존재 필터, 표시 항목 저장, 인쇄 및 XLSX 출력을 제공한다.
- 현재 Google 수집 범위는 캠페인 광고비·노출·클릭이다. 소재·활성 상태·Ads 구매전환·영상 시청 지표를 만들거나 카페24 판매를 Ads 전환으로 표시하지 않는다.
- 기존 Google profit/campaigns API와 서버 집계값을 재사용한다. API·DB·수집 예약 변경은 없다. 상품/캠페인 페이지를 독립적으로 모두 읽고, 중복·누락·조회 중 요약/완전성/수집 상태 변경 시 부분 리포트를 거부한다.
- 검색은 일치하는 상품의 모든 캠페인을 표시한다. 상단 합계는 전체 조회 조건의 서버 집계값임을 화면과 파일에 명시한다. 미연결 광고비·판매 전용 상품·미확정 수치도 보존한다.

검증: 날짜/페이지 로더/그룹/미확정 수치/XLSX 및 기존 날짜·마진 출력 테스트 18개, 기존 Google 화면·권한·탐색 회귀 테스트 19개 통과. 웹 타입 검사·프로덕션 빌드 통과. 로컬 브라우저에서 전일 비교, 검색, 열 표시 저장, 광고비 필터, 기간 종료일/단일 날짜 전환, 실제 XLSX 다운로드를 확인했다. 다운로드 파일의 ZIP/XML에서 선택 열과 상품, 현재/전일 숫자 셀, 수식 없음도 검사했다. 가상 데이터 스크린샷과 다운로드 검증 자료는 git 제외 `reports/google-daily-report/`에 보관한다.
