# Google 소재별 데일리 수집 및 리포트

2026-11-05. 사용자가 승인한 소재별 수집 전환, 기존 데이터 재수집, 화면·엑셀 당일/전일 비교 작업.

## 수집과 저장

기존 계정/일자 캠페인 합계를 유지하면서 `ad_group_ad`의 광고별 실적, 구매 카테고리 전환, 영상 TrueView 조회/시청률, 연결 이미지·영상 정보를 추가 수집한다. 영상 지표를 기본 광고 쿼리와 분리해 이미지 광고의 행이 사라지지 않도록 한다. 전환만 발생한 무지출 광고도 기본 행에 포함한다. 중지·삭제 상태를 필터링하지 않는다.

광고비·노출·클릭을 모든 캠페인별로 정확히 대조한 후 `GoogleCampaignDailyCost.creativeMetrics` JSONB에 `schemaVersion: 1`과 광고별 사실을 저장한다. 기존 source selection, 계정 범위, lease/fencing, 트랜잭션, 커버리지 및 source record link를 그대로 사용한다. 소재의 로고·제목·설명을 추가 광고비 행으로 합산하지 않는다. 여러 미디어가 연결돼도 광고별 비용은 한 번만 저장한다. 이름과 상태는 실적을 읽은 시점의 메타데이터이다.

과거 캠페인 버전은 보존된다. 소재 실적이 없는 기존 버전은 0으로 해석하지 않고 미수집으로 표시한다. JSONB 속성 순서 차이는 새 버전으로 취급하지 않는다. 새 소재값·전환값·메타데이터 변경은 기존 버전 처리로 이력을 남긴다.

## 화면과 엑셀

`GET /google/creatives`는 기존 `data.read` 권한과 같은 source selection/캠페인명 상품 연결을 사용한다. 독립 페이지네이션과 소재별 수집 완료 정보를 반환한다. 기존 판매·마진 계산은 변경하지 않는다.

제품별 광고명·소재 링크, 광고비·노출·클릭·CTR·CPC·CPM, 구매 전환수·CPA·전환매출·Google ROAS, 영상 조회수·조회율·25/50/75/100% 시청률을 표시한다. 계정/광고그룹/광고 ID로 전일을 연결한다. 전일 행 없음과 해당되지 않는 영상 지표는 빈 값으로 유지한다. 구매 전환의 소수는 원본대로 저장하고, 엑셀에는 수치로 내보낸다. Google 전환과 카페24 판매·마진은 각각의 기준으로 표시한다.

엑셀의 표시조건·일반 설명 배너 두 행은 제거하고, 미확정 데이터가 있을 때의 경고만 유지한다. 열 선택은 화면과 엑셀에 공통 적용하며 설정 키는 v2로 분리한다.

## 실제 운영 DB 작업과 검증

- nullable JSONB 열 1개 추가. 기존 캠페인 전체 행의 추가 열을 제외한 fingerprint와 역할 멤버십이 동일함을 rollback 검증 후 실제 적용했다. migration ledger checksum도 기록했다.
- 기존 API 데이터 전체 기간 2026-10-20~2026-11-04, 16일을 정상 manual run으로 재수집했다. 모두 SUCCEEDED, 현재 캠페인 99행 안에 광고×날짜 323행이 저장됐다. 모든 캠페인에서 비용·노출·클릭 대조를 통과했다.
- 실제 보고 서비스에서 11월 3일 소재 10행, 4일 소재 8행의 수집 완료를 확인했다. 기존 캠페인 실적도 같은 API 시점으로 갱신됐다.
- API/수집/기존 계산 회귀 58개, 웹/엑셀 회귀 14개, 배포 범위 보호 10개, 기존 인증 deadline 3개 통과. Prisma 검증과 API/웹 production build 통과.
- 실제 저장 데이터를 사용하는 로컬 production 웹 번들에서 화면 8행, ID별 전일 매칭, 실제 XLSX 다운로드·XML 내용, 열 선택, 검색을 검증했다. 운영 로그인 UI를 직접 조작한 검증과는 구분한다.

비공개 응답과 SQL 적용 영수증, backfill 실행별 이력, 실제 XLSX 및 화면 캡처는 Git에서 제외된 `reports/google-creative-rollout-20261105/`에 보관한다. 실행 도구는 `scripts/google-creative-backfill.ts`이며 기본값은 읽기만 수행하고 `--apply`에서 정상 수집 publication을 실행한다. 배포 완료 정보는 실제 확인 뒤 추가한다.
