# 메타 광고 자동 매핑 규칙 관리

Meta Mappings 상단의 **제품 자동 매핑 규칙**에서 등록하고, 바로 아래 **저장된 메타 광고 매핑 규칙**에서 수정·비활성화·재활성화한다. 기존 카페24 상품/옵션 규칙과는 별개의 광고 분류 규칙이다.

## 수정·비활성화

- 수정: 연결 제품, 매칭 방식, 패턴, 우선순위, 적용 시작·종료일, 메모, 활성 여부를 변경한 뒤 **규칙 저장**.
- 비활성화: 목록의 **비활성화** 버튼. 규칙과 기존 감사 기록은 삭제하지 않는다. 재활성화도 같은 위치에서 가능하다.
- 동시 수정: 조회한 `updatedAt`과 저장 시점의 값이 다르면 409로 거절한다. 새로고침한 뒤 다시 검토한다.
- 읽기 전용 계정에는 수정·활성 상태 변경·다시 적용 버튼이 표시되지 않는다. 모든 변경 API는 `mappings.manage` 권한을 요구한다.

저장·비활성화는 규칙만 변경한다. 과거 실적은 자동으로 바뀌지 않는다. 변경한 규칙을 과거 광고비에 반영하려면 화면의 조회 기간을 맞추고 해당 행의 **선택 기간 다시 적용**을 실행한다.

## 선택 기간 다시 적용

`POST /mappings/product-rules/:id/apply`는 다음 범위만 현재 유효한 규칙으로 다시 판정한다.

- 선택한 기간에서 해당 규칙에 연결된 현재 광고·광고세트 및 미매칭 광고.
- 서비스에서 선택한 CSV/API 원천만 처리한다. 다른 원천 버전이나 원본 금액·수량·노출·클릭 정보는 수정하지 않는다.
- 다른 규칙의 기존 광고 연결, 수동 지정한 광고·광고세트는 보존한다. 적용 기간의 수동 이력도 매처에서 우선한다.
- 비활성화한 규칙을 다시 적용하면 다른 유효 규칙으로 연결하거나 미매칭으로 돌린다. 광고별 판정이 일치할 때 광고세트 연결도 갱신한다.
- 기존 광고세트 매핑 잠금으로 수집/매핑 작업과의 경합을 줄이고, 그룹별 트랜잭션과 감사 이력을 남긴다.

최대 92일, 조회 후보 각 10,000행으로 제한한다. 긴 기간은 나눠 실행한다. 결과에는 변경 광고세트·광고 행 수와 미매칭 광고 수가 표시된다.

기존 상단의 **자동매핑계산**은 미매칭 항목에 대한 기존 동작을 유지한다. 이미 자동 연결된 광고를 규칙 변경에 맞춰 수정할 때는 새 **선택 기간 다시 적용** 버튼을 사용한다.

## API 및 검증

- `PATCH /mappings/product-rules/:id`: 기존 등록 필드와 `expectedUpdatedAt`을 받는다. 잘못된 정규식, 역전된 기간, 동시 수정은 거절한다. 사용자 권한과 수정 전후 조건을 감사 기록으로 보존한다.
- `POST /mappings/product-rules/:id/apply`: `from`, `to` 필수. 원본 실적 대신 매핑 속성만 갱신한다.
- `scripts/meta-mapping-rules.test.ts`: 수정·비활성화·경합·정규식·유효기간·재배분·수동 연결 보존·원천 선택·권한 검증.
- `scripts/meta-mapping-ui.test.tsx`: 관리 버튼, 읽기 전용 표시, 활성 상태, 동시 수정 정보·기간 입력 검증.
- 배포 검증 목록은 기존 메타 매핑 서비스·컨트롤러·DTO 3개 모듈만 추가한다. 재무 계산기와 구글·쿠팡 계산 모듈은 변경하지 않는다.
