# 제품별 통합 성과측정 실행 기록

01~11의 실행 기록을 보관한다. 현재 운영 상태는 `11_결과.md`와 최신 후속 결과를 따른다. 각 세션은 자신의 단계 결과만 작성하고 진행표를 갱신한다.

- `01_확정계약.md`: 01에서 확정한 업무·데이터·API 계약 product-performance-v1.0.0.
- `01_결과.md`: 실제 조사·검증·완료조건과 02 인계.
- `01_현앱조사.md`, `01_네이버조사.md`: 병렬 원천 코드·산식 조사.
- `01_원천대조.md`: 하루/7일 원천 기준선과 네이버 저장 결과 제한 대조.
- `01_독립검토.md`: 계약 검토 지적 및 해소 결과.
- `NN_결과.md`: 실제 수행한 단계의 결과와 검증, 잔여 작업, 다음 시작점.
- `06_API계약.md`: 구현된 통합 집계와 조회 API 계약.
- `10_배포복구계획.md`: 10에서 검증한 운영 적용·중단·복귀 절차.
- `11_전체제품연결.md`: 동일명124개 설정·관측 제목46규칙의 전체 기간 적용과 실제 운영 검증.
- `11_이름연결제외.md`: 추정 연결하지 않은 네이버 단위·광고/자사몰 제목의 검토 목록.
- `../장기간조회_성능보완계획.md`: 장기 조회의 구조 보완 순서와 성능·정확성·배포 기준. 구현 전 계획.

결과 파일에는 비밀값과 주문 개인정보를 기록하지 않는다. 기존 조사 증거는 상위 `research/`에 있고 단계 완료 기록과 구분한다.
