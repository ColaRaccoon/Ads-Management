## 사용자 동작

데일리 보고의 엑셀 다운로드 옆 **엑셀 제품 필터**에서 전체 제품/자사몰/구글/쿠팡/네이버를 선택한다. 선택은 다운로드할 두 시트의 제품 행에만 적용한다. 보고일·전일의 원본 보고서 데이터가 통합 저장 집계에 있는 제품을 포함하며, 확인된 0원·음수·미확정 금액을 이유로 제품을 제외하지 않는다.

자사몰은 Meta 상품 마진, 구글은 Google 마진, 네이버는 손익분석의 저장 상품 결과, 쿠팡은 데일리 제품의 저장 판매·광고 데이터를 기준으로 한다. 전일에만 데이터가 있는 제품도 증감 비교를 위해 포함한다. 공통 등록 목록이나 coverage만으로 생성된 가상의 0원 제품은 포함하지 않는다.

선택된 제품의 자사몰·구글·쿠팡·네이버·전체 16열 금액은 원본 그대로다. 필터된 엑셀에는 필터 전 전체 제품 합계와 미귀속 조정 행을 넣지 않고 이 사실을 표시한다. 전체 제품을 선택하면 기존 엑셀 구성을 유지한다. 대상 0개일 때는 다운로드를 막고 안내하며, 파일명에도 선택 플랫폼을 표시한다.

## 금액 및 화면 보존

- API `daily-products`의 각 제품에 `exportPlatforms` 분류 배열만 추가했다. 제품 목록·current/previous·allProducts·summary·timeseries의 금액은 변경하지 않았다.
- 분류는 기존 단일 스냅샷에서 제품명·두 날짜·선택 계정·선택 플랫폼·발행 참여 정책을 적용한 실제 DIRECT 행을 확인한다. null 제품·0행 partition marker·다른 제품의 문맥·배분 전용 행은 제외한다.
- CAFE24의 명시된 native 채널을 사용하고, 구형 CAFE24는 자사몰로만 분류한다. Meta/Google은 원래 마진 화면의 광고 전용 제품도 포함한다. 네이버는 상품 판매 결과, 쿠팡은 판매/직접 광고 행을 사용한다.
- 엑셀 필터 상태는 기존 조회 필터·query key와 분리했다. 필터를 바꿀 때 새 원천/DB 조회나 계산은 하지 않는다.
- 엑셀 전용 얕은 복사본의 rows만 선택한다. 화면의 요약·상세표·모든 인쇄 모드는 원래 report/data를 계속 사용한다.
- 이전 서버 응답에 제품 분류가 없다면 플랫폼 옵션을 비활성화하고 다시 조회하도록 안내한다. 금액이나 coverage를 근거로 소속을 추측하지 않는다.
- 계산 domain·원천 adapters·repository·Google·daily-sync·DB schema 및 운영 worker는 변경하지 않는다.
