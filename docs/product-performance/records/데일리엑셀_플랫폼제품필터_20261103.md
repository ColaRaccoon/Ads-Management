# 데일리 상세 엑셀 플랫폼 제품 필터

2026-11-03. 최신 원본 `b40c374`, 운영 코드 `efe0d34cf5acedc349537c7f58cd6bb114689bb4`를 기준으로 작업했다. 기존 Meta 수집 재시도·원인 진단 변경을 보존한다.

## 사용자 동작

데일리 보고의 **출력 제품 필터**에서 전체 제품/자사몰/구글/쿠팡/네이버를 선택한다. 선택은 엑셀 두 시트와 인쇄/PDF의 제품 상세표에 적용한다. 사용자 추가 요청으로 보고일 당일 판매수량과 광고비가 모두 확인된 0인 제품은 제외한다. 판매 또는 광고 실적이 있거나 미확정이면 유지한다. 매출 0원이라도 판매수량이 있으면 포함한다. 화면 상세표와 요약 보고서 금액은 유지한다.

자사몰은 Meta 상품 마진, 구글은 Google 마진, 네이버는 손익분석의 저장 상품 결과, 쿠팡은 데일리 제품의 저장 판매·광고 데이터를 기준으로 한다. 전일에만 데이터가 있는 제품은 제외한다. 포함된 제품의 전일 비교 값은 그대로 유지한다. 공통 등록 목록이나 coverage만으로 생성된 가상의 0원 제품은 포함하지 않는다.

선택된 제품의 자사몰·구글·쿠팡·네이버·전체 16열 금액은 원본 그대로다. 필터된 엑셀에는 필터 전 전체 제품 합계와 미귀속 조정 행을 넣지 않고 이 사실을 표시한다. 전체 제품을 선택해도 모든 플랫폼에서 당일 판매·광고 실적이 없는 제품은 제외한다. 대상 0개일 때는 다운로드를 막고 안내하며, 플랫폼 선택 시 파일명에도 표시한다.

## 금액 및 화면 보존

- API `daily-products`의 각 제품에 `exportPlatforms` 분류 배열과 응답 최상위 `exportActivityVersion: 2`를 제공한다. 제품 목록·current/previous·allProducts·summary·timeseries의 금액은 변경하지 않았다.
- 분류는 기존 단일 스냅샷에서 제품명·보고일 당일·선택 계정·선택 플랫폼·발행 참여 정책을 적용한 실제 DIRECT 행을 확인한다. null 제품·0행 partition marker·다른 제품의 문맥·배분 전용 행은 제품 존재의 근거에서 제외한다.
- 저장된 quantity를 정확한 소수 연산으로 합산하고 기존 currentSummary의 표시 광고비를 재사용한다. rowsCount나 매출을 판매수량으로 대신하지 않는다. 제품 존재가 확인되면 기존 광고비에 포함된 배분액도 반영한다. 수량 null/이상/미확정 경고, 수집 미완료, 광고비 미확정은 확인된 0으로 보지 않는다. 금액 집계 호출 횟수와 저장 결과는 바뀌지 않는다.
- CAFE24의 명시된 native 채널을 사용하고, 구형 CAFE24는 자사몰로만 분류한다. Meta/Google은 원래 마진 화면의 광고 전용 제품도 포함한다. 네이버는 상품 판매 결과, 쿠팡은 판매/직접 광고 행을 사용한다.
- 엑셀 필터 상태는 기존 조회 필터·query key와 분리했다. 필터를 바꿀 때 새 원천/DB 조회나 계산은 하지 않는다.
- 출력 전용 얕은 복사본의 rows만 선택한다. 화면의 요약·상세표와 인쇄 요약은 원래 report/data를 계속 사용한다. 인쇄 상세표는 같은 DOM의 필터 제외 행을 print CSS에서만 숨긴다. 금액은 다시 계산하지 않는다.
- 이전 서버 응답에 v2 제품 분류가 없거나 출력 대상이 0개면 엑셀·상세 인쇄·요약+상세 인쇄를 비활성화하고 안내한다. 요약만 인쇄는 유지한다. 브라우저 직접 인쇄에서도 필터 미확인 상세표는 출력하지 않는다.
- 계산 domain·원천 adapters·repository·Google·daily-sync·DB schema 및 운영 worker는 변경하지 않는다.
