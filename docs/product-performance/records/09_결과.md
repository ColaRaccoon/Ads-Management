## 구현과 분석 정의

`GET /api/unified-performance/relationships`와 `/products/performance`의 관계 분석 패널을 추가했다. 공통 조회 조건에 `analysisMedia` JSON 배열과 선택 `changeDate`를 추가하며, 결과 매출과 광고 전 이익의 산점도·시차표·변경일 전후 일평균·원금액/사용/제외 날짜·요일·나머지 매체 비용·7일 이동평균 참고를 제공한다. 신규 API의 구체적인 필드와 오류는 [06 API 계약](06_API계약.md)의 09 추가 절에 기록했다.

- 결과일 t는 사용자 from~to에 고정하고 광고일 t−0/1/3/7/14와 짝짓는다. 이전14일 저장 집계를 추가 조회하고 없는 날짜를 인접일/0으로 대체하지 않는다. 주/월 UI에서도 표본은 일별 원자료다. 조회기간 밖의 결과값으로 표본수를 늘리지 않는다.
- 동일한 read-only RR transaction에서 기본 기간+비교기간+lookback을 읽는다. 확장 snapshotHash와 기본 범위 baseSnapshotHash를 구분하고, 웹은 baseSnapshotHash와 기본 selectionHash를 상단 대시보드에 대조한다. 사용자 ID+권한·전체 필터·매체·변경일·기준 발행 해시로 캐시를 분리하며 이전 선택 placeholder를 사용하지 않는다. 취소 이후 응답을 폐기한다.
- 플랫폼 선택을 매출·비용·이익·시차·전후 입력에 동일하게 적용한다. Meta/Google에 Cafe24 판매를 중복 연결하지 않고 제외 비용을 재배분하지 않는다. analysisMedia/시차/결과값/범례 변경은 상단 플랫폼과 KPI를 바꾸지 않는다. 플랫폼이 바뀌면 패널을 새 조건으로 구성하고 숨은 매체가 남지 않는다.
- 계수는 completeTotals의 수치적 완전성을 충족한 일별 쌍만 사용한다. 매출은 원가 누락 때문에 버리지 않고 광고 전 이익만 별도로 제외한다. 제품 미분류 광고가 있으면 해당 제품의 완전 광고비로 만들지 않는다. 수집 완료 후 사실이 없는 제품은 확인된0, 실제 미수집은 null이다. 계정 범위/제품 참여정책에서 해당 없는 매체는 합산에서 제외하며 진짜 미수집은 null로 유지한다.
- 네이버 ESTIMATED 자체는 표본을 제외하지 않으며 추정/품질을 표시한다. 제외한 네이버의 금액·경고·분석 매체는 남기지 않는다. 다른 매체 광고비가 누락되어도 유효한 대상-결과 쌍은 유지하고 그 맥락은 null로 보인다.
- 확정 계약의 최소 유효60쌍·양쪽 분산>0을 적용한다. 이번 단계는 **제외율20% 초과 시 계수 숨김**을 보수적인 추가 표시 정책으로 정했다. insufficient/constant/excessive missing에는 coefficient null과 원인을 반환하며 산점도·확인된 값은 유지한다. 60일 또는 누락률 기준을 통계적 보장으로 설명하지 않는다.
- Pearson·모집단 표준편차와 전후 통계량은 Decimal로 계산한다. 금액 원문은 보존하고 차트 좌표에서만 Number를 사용하며 안전 범위를 넘는 좌표는 생략한다. 계수·표준편차·전후 평균/평균 증감·비율은 소수10자리다. 7일 이동평균은 연속7개 완료값이 있을 때만 소수6자리로 제공하고 계수/표본에는 넣지 않는다.
- 변경일 이전7/14일은 변경일을 제외하고, 이후7/14일은 변경일을 포함한다. 사용자 기간 밖을 전후 비교에 넣지 않는다. 지표별 유효/제외수와 부분 평균을 제공하되 창이 불완전하면 전체 창의 증감은 null+INCOMPLETE_WINDOW다. 비양수 기저는 증감률 null이다.
- 제품을 지정하고 판매처3개+전체 계정일 때만 **제품 전체 매출**로 부른다. 부분 판매처/명시 계정/전체 제품은 **선택 판매처 합산 매출**이다. 가격·행사·품절 이벤트는 연결되지 않았다고 명시하고 가상 이벤트를 만들지 않았다. 요일과 나머지 매체 비용을 함께 보여준다.

사용자 표현은 **광고비 증가 기간에 매출이 증가하는지 함께 관찰**, **관측 관계이며 인과효과가 아님**, **큰 시차 계수만으로 효과 발생일을 확정하지 않음**이다. 순이익은 광고비를 직접 차감하므로 결과값에서 제외하고 매출/광고 전 이익만 비교한다. 자동 최적시차·효과/인과모델·예산 변경은 구현하지 않았다.
