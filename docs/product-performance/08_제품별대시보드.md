# 08 제품별 대시보드

## 목표와 선행 조건

제품 A의 모든 적용 광고비, 판매처별 매출, 추정이익과 기간 변화를 한 화면에서 확인한다. 07 DONE이 필요하다.

[시작 안내](00_시작안내.md), [공통 규칙](공통_작업규칙.md), 전체 설계의 5·6·9절, `records/06_API계약.md`, `records/07_결과.md`와 웹 AGENTS.md를 읽는다.

## 이번 단계 작업

- `/products/performance`와 실제 사용하는 `components/app-shell.tsx` 메뉴에 제품 통합 성과를 추가한다.
- 고정 제품명, 계정/스토어, 날짜, 비교기간, 일/주/월 필터를 구현한다. 서버에서 이름을 정확히 해석한다.
- 운영매출, 전체/확인된 광고비, 광고 전 이익, 추정 순이익, MER, 데이터 상태 카드를 구현한다.
- 매체별 광고비 누적 막대, 매출/이익 추이, 100% 광고비 구성, 판매처 매출 구성과 비교표를 구현한다.
- 그래프 날짜축/툴팁을 맞추고 통화·비율·%p 단위를 구분한다. 누락일은 선을 끊고 완료된 0원만 0으로 표시한다.
- 원가 미입력·미매핑·미배분·수집 누락·마지막 갱신·계산 기준을 진단 패널과 연결한다.
- 분석용 광고계열 표시를 꺼도 공식 총광고비/총이익은 바뀌지 않게 한다. 판매처 필터로 광고비 귀속을 임의 변경하지 않는다.
- 기존 Recharts/React Query를 활용해 실제 API를 연결한다. 데이터 없음·부분 완료·실패·로딩 상태를 구현한다.

## 필수 병렬 분담

서브에이전트 A는 KPI/비교표/필터, B는 그래프/진단 패널을 맡는다. 주 에이전트가 공통 쿼리·타입·라우팅을 통합한다. 별도 담당자는 실제 API 시나리오와 금액 표시를 검토한다.

## 완료 조건

실제 API 집계와 카드·표·툴팁의 금액을 대조한다. 일/주/월, 동일일수·전주·직접 비교, 전기0, 적자/흑자 전환, 부분월, 누락일을 검증한다. 미완전 데이터가 전체로 표시되지 않아야 한다.

기존 플랫폼 메뉴/화면과 권한 처리가 유지되고 타입/빌드가 통과해야 한다. UI가 가능한 실행 환경에서 확인되지 않았다면 미확인 범위를 명시한다.

`records/08_결과.md`에 화면 검증, 실제 API 연결과 표시 산식을 남긴다. 관계 분석 그래프/계수는 09에서 추가한다.
