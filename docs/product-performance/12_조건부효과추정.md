# 12 조건부 효과 추정

> 02단계 이후 필수 적용: [플랫폼 선택과 네이버 데이터 정책](플랫폼선택과네이버데이터정책.md). 이 추가 정책은 플랫폼 포함/제외·네이버 정확도에 한해 기존 전체 설계·공통 규칙·01 계약의 상충 문구보다 우선한다. 진행 중인 01 문서와 기록은 변경하지 않는다.

선택 플랫폼과 학습/검증 데이터 범위를 고정하고 캐시/모델 결과에도 선택을 표시한다. 네이버 추정 데이터 포함 여부를 명시한다. 모델 적합성 부족은 이 조건부 단계에서 다루며 이미 완료한 통합 조회/체크박스 기능을 되돌리거나 네이버 정답 검증을 필수화하지 않는다.

## 목표와 착수 조건

광고비의 변화가 제품 매출에 미친 효과를 추정할 조건이 갖춰졌는지 판단하고, 가능한 경우 모델 또는 실험 설계를 구현한다. 11 완료 후 별도로 이 단계가 지정되었을 때 수행한다. 기본 상태는 DEFERRED이며 01~11의 완료를 막지 않는다.

[시작 안내](00_시작안내.md), [공통 규칙](공통_작업규칙.md), 전체 설계의 7절, `records/09_결과.md`, `records/11_결과.md`를 읽는다. 적용할 통계 방법의 공식/1차 자료를 확인한다.

## 이번 단계 작업

- 장기 보유기간, 유효 관측 수, 계절성, 가격·행사·재고·다른 매체 변화와 광고비 독립 변동을 진단한다.
- 여러 매체 예산이 함께 움직여 개별 효과를 분리할 수 없는지 확인한다. 근거가 부족하면 계수를 산출해 효과로 발표하지 않는다.
- 타당한 경우 결과값/추정대상/통제변수/시차/가정/불확실성 기준을 먼저 정의하고 시간순 검증기간을 분리한다.
- 적합도와 인과 타당성을 구분하고 민감도·불확실성 구간·적용 범위를 결과에 포함한다.
- 관측 데이터만으로 부족하면 지역·상품군 대조군 등의 실험안을 구체화한다. 실제 광고 예산 변경이나 실험 집행은 자동으로 실행하지 않는다.

## 필수 병렬 분담

서브에이전트 A는 데이터 적합성과 혼동 요인을, B는 모델/실험과 검증 설계를 맡는다. 주 에이전트가 정의를 통합하고 독립 검토로 인과 해석의 과장을 확인한다.

## 완료 조건과 기록

효과 추정이 가능한 경우 모델·가정·불확실성과 시간순 검증을 함께 제공한다. 불가능하면 필요한 데이터/실험과 충족 기준을 기록하고 모델 미구현 상태를 분명히 남긴다. ‘부적합 판정 완료’와 ‘효과 모델 구현 완료’를 구분한다.

`records/12_결과.md`에 판정과 근거, 구현 여부, 검증, 추후 조건을 기록한다. 데이터 적합성 확인만으로 실행되지 않은 모델을 DONE으로 처리하지 않는다.
