# 제품별 통합 성과측정 세션별 실행 안내

이 작업은 한 세션에서 모든 구현과 운영 검증을 끝내기에는 크다. 원천마다 매출·비용·상품명 규칙이 다르고, 신규 DB 구조·백엔드·설정 화면·대시보드·관계 분석이 필요하다. **필수 11단계와 조건부 고도화 1단계**로 나누고, 사용자가 지정한 단계 하나를 새 세션이 맡는다.

단계 하나가 반드시 세션 하나 안에 끝난다는 뜻은 아니다. 완료 조건을 충족하지 못하면 해당 단계를 IN_PROGRESS로 남기고 다음 세션에서 같은 단계부터 이어간다. 한 세션이 다음 단계까지 자동으로 연속 실행하지 않는다.

각 단계 종료에는 **검증·인계 기록뿐 아니라 해당 단계 변경의 Git 커밋과 원격 개발 브랜치 푸시·반영 확인**도 포함한다. 상세 절차는 [공통 작업규칙](공통_작업규칙.md)의 ‘단계별 Git 기록과 원격 반영’을 따른다. 다른 세션의 미커밋 작업은 함께 올리지 않고, 운영 브랜치 병합/배포와 개발 기록용 푸시를 구분한다.
