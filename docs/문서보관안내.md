## 과거 기록을 읽거나 재사용할 때

보관 묶음 내부 상대경로는 유지했다. 다른 폴더에서 `docs/daily-data-automation/...`를 가리키는 과거 안내 링크는 위 보관 루트 아래 동일 상대경로에서 찾는다. 별도 PC/새 체크아웃에서는 보관 파일도 별도로 가져와야 한다.

과거 phase10 도구 일부는 이전 문서 경로를 읽기·해시·수정 입력으로 사용한다. 예를 들어 `phase10-cafe-pair-recovery-20261020.ps1`, `phase10-final-closeout-20261021.mjs`, `phase10-update-final-docs-20261021.mjs`가 해당한다. 과거 도구를 재사용하려면 보관 명세를 기준으로 필요한 문서 경로를 먼저 복원하거나 명시적으로 새 경로를 적용해야 한다. 해시가 결속된 역사 증거와 도구를 임의 수정하지 않았다.

현재 앱·패키지와 정규 빌드/배포 설정에서 이 문서들을 실행 입력으로 읽는 직접 참조는 조사에서 발견하지 않았다. 과거 코드 도구를 모두 재실행해 확인한 것은 아니다. 보관된 문서에 남은 당시 미완료/운영 상태를 현재 성공으로 바꾸지 않았다.

이 이동은 현재 작업 폴더의 파일만 줄인다. Git 과거 커밋의 저장 용량은 줄지 않으며 이력을 재작성하지 않았다. 커밋 전에는 Git 상태에 이동 원본이 삭제로 나타난다.
