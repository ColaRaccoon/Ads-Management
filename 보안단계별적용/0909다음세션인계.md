- COMMIT 결과 불명확 또는 commit 후 positive verify 실패: activation을 다시 실행하지 않는다.
- unknown 상태: 별도 승인된 admin read-only catalog/Pooler Logs 분류부터 수행한다.
- remote credential이 이미 active일 개연성이 확인된 경우에만 새 별도 승인으로 `Mode VerifyOnly`를

  drop은 하지 않는다.
- destructive drop은 이번 gate 범위 밖이며 별도 exact 승인 없이는 실행하지 않는다.

stale temp, cleanup failure, marker/state mismatch, unexpected item, 두 번째 attempt는 fail closed한다.
matching owner label+cidfile+full container ID가 확인된 자기 container만 정리하고 이름 충돌 container는
