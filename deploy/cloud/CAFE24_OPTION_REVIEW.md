# Cafe24 판매자 옵션 검증

2026-11-01 사용자 요청으로 판매자 옵션 검증의 30일 만료를 제거했다. 이 문서는 이전 단계 기록의 seller-dropdown 월간 재확인 안내를 대체한다. API 버전, 전체 품목 포함 정책, 결제수단 대조 등 다른 검증의 수명은 변경하지 않는다.

## 정상 수집

`DAILY_SYNC_CAFE24_SELLER_DROPDOWN=true`와 실제 확인일인 `DAILY_SYNC_CAFE24_SELLER_DROPDOWN_VERIFIED_AT=YYYY-MM-DD`를 유지한다. 확인일은 기록이므로 시간이 지났다는 이유로 갱신하지 않는다. 누락·잘못된 날짜·미래 확인일은 계속 거절한다.

`DAILY_SYNC_CAFE24_SELLER_DROPDOWN_REVIEW_REQUIRED`가 없거나 `false`이면 기존 확인을 사용한다. 새 값 `true` 및 잘못된 값은 `FIELD_UNSUPPORTED` / `CAFE24_EVIDENCE_SELLER_OPTIONS`로 주문 조회와 인증 갱신 전에 중단한다. 수동·예약 경로에 동일하게 적용된다.

## 옵션 설정이 변경됐을 때

몰 운영자가 자유 입력 추가 등 확인 조건에 영향을 주는 설정 변경을 알게 되면 위 `REVIEW_REQUIRED=true`를 운영 설정에 적용한다. 기존 `SELLER_DROPDOWN=false`로 확인을 철회하는 방법도 계속 유효하다. 실제 설정과 원본 옵션/상품·원가 연결을 검토한 뒤 확인일을 기록하고, 드롭다운 조건이 충족될 때만 `SELLER_DROPDOWN=true`, `REVIEW_REQUIRED=false`로 적용한다. 날짜만 바꿔도 재확인 표시가 해제되지는 않는다.

현재 수집은 주문·품목 조회를 사용하므로 카페24 관리자 화면의 옵션 편집 이벤트를 자동 구독하거나 설정 변경을 직접 탐지하지 않는다. 이 변경을 자동 감지 기능이라고 설명하지 않는다. 설정 변경을 알리는 절차와 실제 데이터 검증을 함께 사용한다.

## 실제 입력이 잘못됐을 때

옵션 누락/null/공백/제어 문자/길이 초과, 상품명과 옵션 조합 충돌, 허용하지 않은 상태, 조회 중 품목 변경 및 불완전 페이지 등 기존 검증을 유지한다. 실패 시 기존 runner가 ACTION_REQUIRED 또는 해당 실패 상태와 진단 코드를 남기고 성공 데이터로 발행하지 않는다. 기존 성공 자료는 보존한다. 상품 미매칭은 오류와 구분하고 원본을 보존하며 임의 원가를 연결하지 않는다.

재확인은 실제 원인을 해결한 뒤 진행한다. 이력의 실패 run을 성공으로 고쳐 쓰거나 지난 예약을 새 정시 실행으로 위장하지 않는다.
